Application Menus

The application menu provides mouse and keyboard access to editor actions, organized under File, Edit, Search, View, Tools, and Help. Plugins can add their own actions and submenus.

Show the menu bar​

The menu bar is hidden by default. Press Alt+Shift+M to show or hide it. The treeview toolbar's menu button toggles the same setting. You can open the popup with Alt+M even when the bar is hidden. On macOS, use Option instead of Alt.

  • User Module
  • Settings UI

Open your user module and enable the bar:

local config = require "core.config"
config.show_menubar = true

Set it to false to hide the bar.

Open Settings with the ui:settings command, then enable Core > User Interface > Show Menu Bar. The visibility change applies immediately and saved preferences override the default on later starts.

When the labels cannot all fit, the bar displays a single Menu button containing the same groups.

Navigate and run actions​

Click a group to open it. Move the pointer to another group to switch menus, or click the active group again to close it. Submenus expand from entries marked with an arrow.

Opening the menu keeps the document's selection and focus available for editing actions. Unavailable actions remain visible but disabled. Checkmarks show enabled options, and assigned keyboard shortcuts appear beside actions. Available plugin actions depend on which plugins are enabled.

KeyAction
Left/RightSwitch top-level groups when no submenu entry is selected.
DownSelect the first entry after opening a group.
Up/DownMove through entries.
RightOpen the selected submenu.
LeftReturn from a submenu to its parent.
EnterRun the selected action or open its submenu.
EscapeClose one submenu at a time, then the main popup.

Click outside the popup to dismiss it. Opening or switching a top-level group leaves its entries unselected until you move into them.

Menu groups​

GroupCommon actions
FileCreate, open, save, reload, rename, and close files; manage project folders.
EditUndo/redo, clipboard operations, line and selection editing, case conversion, line endings, and encodings.
SearchFind and replace, previous/next matches, and Go to Line.
ViewSplit panes, switch focus and tabs, toggle interface elements, and preview Markdown.
ToolsOpen the command palette, log, user/project configuration, and enabled plugin tools.
HelpOpen documentation, project links, and About.

Animations​

Showing and hiding the bar follows the editor's animation settings. To disable just this height animation, add this to your user module:

local config = require "core.config"
config.disabled_transitions.menubar = true

You can also enable Menu Bar under Core > Graphics > Disable Transitions in Settings.

Commands and shortcuts​

CommandDefault shortcutAction
menu-bar:openAlt+MOpen or close the popup, including when the bar is hidden.
menu-bar:toggleAlt+Shift+MToggle bar visibility.
menu-bar:showNoneShow the bar.
menu-bar:hideNoneHide the bar.

See Command Palette for searching actions by name. Plugin authors can extend menus using the Application Menus developer guide.
