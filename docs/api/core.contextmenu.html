(method) core.view:show_floating(options?: core.view.floating_transition)
  -> view: core.view

Show or raise the view in RootView's floating layer and apply its focus policy. Requires a view detached from its node and parent container. Reopening cancels a pending close and its completion callback. Disabled transitions apply placement and run the completion callback immediately.

@param options?: core.view.floating_transition — Optional opening slide (from) and callback

@return view: core.view — This view, for chaining

show_items​

(method) core.contextmenu:show_items(source: core.contextmenu.item[]|fun():core.contextmenu.item[], x: number, y: number, options?: core.contextmenu.show_options)
  -> shown: boolean

Show an explicit menu tree. Context registrations retain predicate filtering. Builds a new snapshot for this opening and leaves the rows unselected.

@param source: core.contextmenu.item[]|fun():core.contextmenu.item[] — Entry definitions or an opening-time provider

@param x: number — Screen x coordinate

@param y: number — Screen y coordinate

@param options?: core.contextmenu.show_options — Placement and unavailable-entry policy

@return shown: boolean — Whether at least one entry was available to show

supports_text_input​

(method) core.view:supports_text_input()
  -> boolean

Whether this view accepts text input (enables IME). Override and return true for text editors and input fields.

try_close​

(method) core.view:try_close(do_close: function)

Called when view is requested to close (e.g., tab close button). Override to show confirmation dialogs for unsaved changes. Example: core.command_view:enter("Save?", \{submit = do_close\})

@param do_close: function — Call this function to actually close the view

update​

(method) core.contextmenu:update()

Update scrolling, opening animation, and delayed submenu navigation. Font or scale changes remeasure the snapshot without rebuilding entries or predicates.

update_floating​

(method) core.view:update_floating()

Update anchor placement or advance an opening or closing slide. RootView calls this before update() for each shown floating view. Completes removal and invokes the transition callback when a slide finishes.

update_scrollbar​

(method) core.view:update_scrollbar()

Update scrollbar positions and sizes. Called automatically by update(). Rarely needs to be called manually.
